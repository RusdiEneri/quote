REST API Reference & Endpoints

Directly integrate Telegram quote generation into your Telegram bots, web apps, or backend services using our public endpoints.

Method Endpoint Description Content-Type
POST https://qc.mangrusdi.my.id/generate Main quote generator endpoint (returns base64 image and dimensions) application/json
POST https://qc.mangrusdi.my.id/api/generate Secondary proxy route for flexible integrations application/json
GET https://qc.mangrusdi.my.id/status Operational health check and service uptime info application/json

Request Payload Schema (JSON)

Payload properties accepted by the POST /generate endpoint.

Field Type Requirement Description
messages Array<Object> Required Array of message objects to be stacked into quote bubble canvas.
messages[].from.name string Required Sender display name shown at the top of the chat bubble.
messages[].text string Required The text message content. Supports Markdown & emojis.
messages[].from.title string Optional Role badge next to the sender name (e.g. "Admin", "Owner").
messages[].from.photo.url string Optional Public image URL or base64 data URI for sender avatar.
messages[].replyMessage Object Optional Quoted reply box containing name and text.
type string Optional "quote" (sticker, 512px max), "stories" (9:16), or "image" (canvas).
format string Optional Image compression format: "png" (lossless) or "webp".
backgroundColor string Optional Hex color string for chat bubble background (default: "#1b1e23").
watermark string Optional Branding watermark text applied on Stories and Canvas layouts.

Supported Output Layouts

Choose the layout format suited to your media channel: transparent stickers, vertical stories, or wide canvas cards.

Quote Bubble (Sticker)

Standard Telegram message bubble rendered with transparent background, ideal for creating Telegram sticker packs and bot replies.

  • 512px standard sticker width
  • Full alpha channel transparency
  • Supports replies and badges

Vertical Stories (9:16)

High-resolution vertical format designed for Telegram Stories, WhatsApp Status, and Instagram Reels with custom background themes.

  • 1080 x 1920 portrait canvas
  • 4x supersampling resolution
  • Custom watermark placement

Image Card (Canvas)

Horizontal card presentation featuring elevation shadows, rounded frames, and clean padding for social media embeds and articles.

  • 1280 x 720 landscape canvas
  • Soft elevation shadow
  • Lossless PNG and compact WebP

Frequently Asked Questions

Common questions regarding integration, file formats, and server capabilities.

How do I generate quote stickers using the REST API?
Send an HTTP POST request to https://qc.mangrusdi.my.id/generate with header Content-Type: application/json. Include a messages array containing the sender name, avatar URL, and text message. The server processes the canvas in approximately 1 to 2 seconds and returns the resulting base64 image.
Which image formats and transparency settings are supported?
The API natively supports PNG and WebP. For standard sticker bubbles, PNG preserves complete alpha transparency, making it ready to upload directly as a Telegram sticker. WebP provides smaller payloads for web rendering and mobile bandwidth efficiency.
Can I supply local avatar pictures without public hosting?
Yes. The web customizer includes an upload button that reads your local image file and converts it into a base64 data URI (data:image/png;base64,...). The backend accepts both HTTP image links and base64 data URIs for avatars and attachments.
Is there a health check endpoint to monitor API uptime?
Yes. A simple HTTP GET request to https://qc.mangrusdi.my.id/status returns a JSON object containing operational status, server availability, and uptime duration.
